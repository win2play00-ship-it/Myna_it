Business Hours

Report an Issue

When contacting support, please include as much information as possible, such as:

  • Registered Mobile Number
  • User ID (if available)
  • Description of the issue
  • Match ID (if related to a quiz)
  • Transaction ID (for payment issues)
  • Screenshots (if applicable)

Providing complete information helps us resolve your issue more quickly.

Response Time

Our goal is to respond within:

  • General Queries: Within 24 Hours
  • Payment Related Queries: Within 24–48 Hours
  • Technical Issues: Depending on the complexity of the issue

Important Notice

Myna will never ask for your:

  • OTP
  • UPI PIN
  • Bank Password
  • Debit Card PIN
  • Credit Card CVV
  • Account Password

If anyone requests this information while claiming to represent Myna, do not share it and report the incident immediately.
