1. Our Commitment

At Myna, fair competition is our highest priority. Every quiz match is designed to provide an equal opportunity for every player to compete honestly. We use secure server-side systems to ensure that match results are accurate, transparent, and free from manipulation.

2. Equal Opportunity

Every participant receives:

  • The same quiz questions.
  • The same answer options.
  • The same time limit for every question.
  • The same scoring rules.
  • The same opportunity to win.

3. Secure Match Processing

To protect the integrity of every contest, Myna performs all critical calculations on secure backend servers.

  • Question validation.
  • Answer verification.
  • Score calculation.
  • Winner determination.
  • Tie detection.
  • Prize calculation.
  • Wallet settlement.

Client-side modifications cannot change match results.

4. Scoring System

Scores are calculated using the official Myna scoring algorithm.

The score may consider:

  • Correct answers.
  • Time taken to answer.
  • Total quiz performance.

The server's calculated result is final.

5. Tie Matches

If both players achieve the same final result according to Myna's scoring system:

  • The match will be declared a tie.
  • The prize amount may be divided equally between eligible players according to the contest rules.
  • The server determines the final outcome.

6. Prohibited Activities

The following activities are strictly prohibited:

  • Using bots or automated software.
  • Using modified or hacked applications.
  • Reverse engineering the application.
  • Multiple account creation.
  • Account sharing.
  • Using fake identities.
  • Collusion with other players.
  • Attempting to manipulate quiz outcomes.
  • Using unauthorized scripts or software.
  • Network manipulation or packet modification.
  • Exploiting software bugs or vulnerabilities.
  • Payment fraud.
  • Money laundering.

7. Fraud Detection

Myna continuously monitors gameplay to detect suspicious activities.

This may include:

  • Duplicate accounts.
  • Abnormal gameplay patterns.
  • Repeated suspicious wins.
  • Device abuse.
  • Payment anomalies.
  • Location inconsistencies.
  • Multiple accounts using the same device or payment method.

8. Investigations

If suspicious activity is detected, Myna may investigate the account. During the investigation we may:

  • Temporarily suspend the account.
  • Delay withdrawals.
  • Request identity verification.
  • Review gameplay history.
  • Review wallet transactions.
  • Review payment records.

9. Penalties

Violation of this Fair Play Policy may result in one or more of the following actions:

  • Warning.
  • Temporary account suspension.
  • Permanent account termination.
  • Cancellation of contests.
  • Forfeiture of winnings.
  • Withdrawal restrictions.
  • Reporting to appropriate authorities where required by law.

10. Match Results

All match results are generated using secure server-side processing.

Server records, including submitted answers, timestamps, scores, and wallet settlements, are considered the official record of the contest.

11. User Responsibilities

Every user is responsible for:

  • Providing accurate account information.
  • Keeping login credentials secure.
  • Maintaining a stable internet connection.
  • Using only the official Myna application.
  • Following all platform rules.

12. Policy Updates

Myna may update this Fair Play Policy from time to time. Updated versions become effective immediately upon publication on this page. Continued use of the application indicates acceptance of the updated policy.
